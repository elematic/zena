## Release notes

### The first preview

This is the first release of Zena, a statically typed language that compiles to WebAssembly GC. It is a preview: the language, the standard library and the tools will change, and a release before 1.0 can break code that compiled with the one before.

The release is the `zena` command for macOS (Apple Silicon), Linux (x86_64 and ARM64) and Windows (x86_64). It has the compiler, the standard library, the formatter, the linter, the test runner, the documentation extractor, the language server and the package manager built in. The VS Code extension is released with it.
