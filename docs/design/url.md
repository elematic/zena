# URL Library (`zena:url`)

The design and plan for the `zena:url` library (`URL`, `URLSearchParams`, and
the future `URLPattern` / `URLPatternList` exports) lives with the library
itself:

  user-facing overview and planned API.
- [packages/stdlib/zena/url/DESIGN.md](../../packages/stdlib/zena/url/DESIGN.md) —
  full design: specs, API (including the immutable `with*` model, `UrlString`

  implementation phases.
