# Known Bugs

Bugs are tracked as GitHub issues: <https://github.com/elematic/zena/issues>.
File one there rather than adding an entry here.

This file used to hold them. Every entry was verified against the compiler and
moved out in August 2026; about a quarter turned out to be already fixed and
were deleted rather than filed. `git log -p --follow BUGS.md` has the full text
of all of them.

Other files still say "see BUGS.md" next to a workaround or a deferred ruling.
Those references predate the move. Each names the bug it means, so search the
issue tracker for that name.
